# posts-clinica-midia

Hospedagem pública e temporária das artes do `posts-clinica`.

**Por que este repositório é público:** a API de publicação do Instagram não
aceita upload de bytes — ela busca a imagem numa URL pública. Este repositório
existe só para dar essa URL no instante da publicação.

**O que entra aqui:** apenas arte de divulgação já aprovada, que segundos depois
vira post público no Instagram. Nada mais.

**O que NUNCA entra aqui:** dado de paciente, documento clínico, credencial,
token, ou qualquer arquivo do sistema da clínica. Este repositório não tem
relação com o prontuário.

Os arquivos são apagados depois que a publicação confirma.
